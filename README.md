# 학년별 영단어

교육부 2022 개정 영어과 교육과정 기본 어휘 3,000단어로 초1부터 고3까지 학년별로 공부하는 영단어 웹앱(PWA)입니다.
iPhone Safari에서 "홈 화면에 추가"로 설치하면 앱처럼 쓸 수 있고, 인터넷이 없어도 동작합니다.

## 기능
- 학년 선택 (초1~고3), 단원별 20단어
- 플래시카드: 알아요 / 헷갈려요 / 몰라요
- 퀴즈: 4지선다 고르기, 직접 쓰기 (영어 → 뜻, 뜻 → 영어)
- 간격 반복 복습 (1·3·7·14·30일)
- 오답노트 (3번 연속 맞히면 제외)
- 하루 목표와 연속 학습 일수

## 파일
- `index.html`, `app.js`, `style.css`: 앱 본체
- `words.js`: 앱이 읽는 단어 데이터
- `sw.js`, `manifest.json`, `icons/`: 설치와 오프라인 지원
- `data/words.csv`: 학년, 단어, 품사, 뜻 목록 (엑셀로 열기)
- `data/base_words.csv`: 공식 문서에서 추출한 원본 목록

## 단어 출처
교육부 고시 2022 개정 영어과 교육과정 [별표 3] 기본 어휘. 학년 배정과 한글 뜻은 학습 편의를 위해 이 앱에서 정한 것입니다.

## 수정 후 반영
파일을 고친 뒤에는 `sw.js`의 `VERSION` 값을 올려야 설치된 앱에 새 버전이 반영됩니다.
